## 你报的问题

> 大乐透 26111 期，票面开奖日 **2026-09-28**（今天），当晚 **21:30** 才开奖。
> 但下午 18:12 打开 App，首页就提示「已过开奖日期」。

## 根因

**同一个判断，代码里写了两套，口径漂移了。**

| 位置 | 判断 |
|---|---|
| 核验层 `PrizeService.isDrawTimePassed` | 看**时间**：当天要过 22:00 ✅ |
| 查询层 SQL `WHERE draw_date <= :today` | 只看**日期** ❌ |

日期一到，SQL 就把票当「已过开奖」捞进待核验队列 → 黄条 / 状态标签 / 计数全跟着错。
**两套逻辑各自看都对，合起来就错**，而且只在「开奖日当天 22:00 前」这个窗口暴露。

## 修法

把判定收敛成**唯一一份** `core/DrawSchedule.kt`，核验 / 查询 / 展示三层都调它。

最巧的一处是 `checkCutoff`：**不去 SQL 里拼时间，而是把「截止日」提前一天** ——
`draw_date <= cutoff` 天然等价于「已过开奖时间」，跨月/跨年自动处理。
