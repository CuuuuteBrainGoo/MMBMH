# v1.6.0 交付说明

## 本次做的两件事

### 1. 进详情页再返回，列表停在你原来的位置

**根因不在列表，在路由。**
详情页不是一个独立页面，而是「有选中票」这个状态，
它在页面判断里**优先级高于路由**。所以一点进详情，首页**整个被从界面上撤下来**了 ——
它内部记着的「滑到第几行」跟着一起没了，返回时是重新建的，自然回到顶部。

**修法**：把「滑到哪一行」这个记录**提到外层**存放（`LedgerRootContent`）。
这样撤下来再放回去，记录都还在。

顺带白捡两件事：系统切深浅色 / 旋转屏幕后位置也不丢；切设置页再回首页也停在原位。

### 2. 每张票加展示编号

**编号 = 这张票在列表里从下往上数第几个。**

列表按开奖日期倒序排（越新越靠前），所以：
- 列表**最下面**那张（最旧）= `1`
- 列表**最上面**那张（最新）= **总张数**

「越新数字越大」天然成立，而且编号永远连续、不跳号。

按你确认的三条边界实现：
- 只给成功录入的票编号（草稿不算）
- 后录的票若日期在前，就插到那个位置，**其后的票编号全部更新**
- **筛选时编号不变**（始终按全部票算，不是按筛出来的算）

## 附带编号的位置

| 位置 | 效果 |
|---|---|
| 首页每张票最左边 | `#12` 徽章，等宽字体，数字能一眼比大小 |
| 详情页顶部 + 票面信息 | 和列表上那张编号一致 |
| 核验 / 兑奖 / 手动标记的提示 | 形如 `#12 · 这张票没中奖` |
| 首页三条提示（待兑奖 / 查不到结果 / 奖金待确认） | 附编号清单，如 `#12、#7、#3` |
| **判重提示** | 「与已有彩票 **#12** 完全一致」 |

## 顺手修掉的一个真问题

判重提示以前写的是「与已有彩票 **#47** 完全一致」——
那个 `47` 是**数据库内部编号**，你在界面上任何地方都看不到它，等于给了个没用的指路牌。
现在换成了首页列表上的展示编号，你照着就能对上号。

## 编号的颜色决定

**编号是纯标识，不带任何含义**，所以没占用任何语义色
（金色=同一期第几张 / 奖金待确认，红=中奖，紫=已过期）。
用的是中性灰 + 浅底 + 等宽字体 —— 醒目但不误导。

## 已知取舍（说明一下，不是 bug）

**删掉中间某张票，它上面那些票的编号会各减 1。**

这是刻意的：换来的是「编号永远连续 + 数字越大越新永远成立」。
如果改成「入账时分配、永不变」，编号在按日期排序的列表里就会是乱序的
（`#3` 排到 `#12` 上面），你照着编号找反而更费劲。

同理，**改一张票的开奖日期，它的编号会变** —— 因为编号就是「它在列表里的位置」。

## 两条只能真机确认的

1. **滚动位置保留** —— 这是 Compose 的运行时行为，单测覆盖不到
2. **编号徽章的实际观感** —— 大小、颜色对比够不够，得真机看
