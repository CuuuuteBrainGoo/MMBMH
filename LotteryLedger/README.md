# 彩票账本（LotteryLedger）

个人自用 Android 彩票账本。只做 Android，只服务个人账本，不做彩票信息门户。

> **面向使用者的说明**（怎么装、怎么配 API Key、每个平台去哪申请）
> 在**仓库根目录的 `README.md`**。本文档是开发视角：进度、关键设计约束、目录结构、测试。

## 安装

```
apk/LotteryLedger-v1.6.0-debug-signed.apk
```

- 首次进入需在「设置 → AI 平台」添加平台并填 API Key，否则「录入彩票」会提示先去配置。
- 建议先用**智谱 `glm-4v-flash`（免费）**把流程跑通，再考虑换豆包 / 火山方舟追求识别率。

## 关键设计（不可违背）

1. **AI 只读票** —— 提示词里三条硬禁令：禁止判中奖、禁止算奖金、禁止"纠正"号码。识别结果只通过
   `BetRules` 的本地规则校验，不采信模型自报的置信度。
2. **照片不长期保存** —— 私有 `cacheDir/ticket_tmp`，重新编码 JPEG（天然剥离 EXIF/GPS），
   识别完立即删除，App 启动时扫描清理残留。从相册导入只读，绝不删用户原照片。
3. **同一实体票不重复入账** —— 靠票身份指纹，三优先级：
   ① 验票码/条码值/票号 ② 站号+终端号+流水号+秒级出票时间 ③ 弱组合。
   只有 ①② 能阻止入账；③ 和投注内容相同**只能提示**。
4. **号码全同也是两张票** —— 投注内容相同绝不阻断入账（`FingerprintsTest` 专门锁死）。
5. **票面开奖日期优先** —— 不维护休市表，不做程序推算。
6. **一、二等奖只判奖级，奖金用户手填** —— 待确认时首页显式提示且**不给最终盈亏数字**；
   用 0 冒充一等奖是最糟的做法。
7. **平台全可替换** —— 平台、模型名、接口地址全部可改；统一走 OpenAI 兼容协议。
8. **预填值里不能有任何具体账号的资源标识** —— `ProviderDefaults` 的预填值会发给每一个
   装了 App 的人，所以只放一眼假的占位符（如 `ep-xxxxxxxxxxxxxxxx`）。

## 目录结构

```
app/src/main/java/com/bro/lotteryledger/
├── core/            纯 Kotlin 逻辑（不 import android.*，可 JVM 单测）
│   ├── Models.kt           统一识别数据结构
│   ├── BetRules.kt         规则引擎：结构校验 + 组合数 + 金额
│   ├── Fingerprints.kt     三类指纹与去重判定
│   ├── PrizeRules.kt       奖级判定与固定奖金
│   ├── RedemptionDeadline.kt 兑奖期限（含国庆/春节顺延，春节表 2025~2035）
│   ├── TicketCode.kt       展示编号（编号 = 列表位置，越大越新）
│   ├── CrashBeacon.kt      崩溃落盘（带版本号，供下次启动比对）
│   ├── LedgerReports.kt    统计聚合（口径与首页总账一致）
│   └── ...                 TicketFilter / TicketStats / IssueSeq / ThemeMode 等
├── ai/              OpenAI 兼容客户端 + 识别流程编排 + 连通性探针
├── db/              Room 实体 / DAO / 数据库
├── image/           图片管道（EXIF 剥离、缩放、缓存清理）
├── net/             开奖接口客户端 + 定时对奖 Worker
├── repo/            台账仓储 + 备份编解码 + 奖金服务 + 设置存储
├── security/        API Key 加密存储（AES-256-GCM + Android Keystore）
└── ui/              Compose 界面（Home / Capture / Review / Detail / Reports / Settings / Help / Log）
```

## 测试

```bash
gradle testDebugUnitTest
```

**约 460 个纯 JVM 单测**（37 个测试文件），覆盖：

- 规则层：复式注数（C(6,5)×C(2,2)=6、C(6,5)×C(3,2)=18、C(7,6)×C(2,1)=14）、追加 3 元/注、
  号码格式非法不自动补零
- 去重层：**号码全同两票判定为待确认而非重复**、强指纹命中阻止入账、弱指纹不阻断、
  秒级时间差视为不同票
- 对奖层：奖级判定、奖池 ≥8 亿的升档金额、兑奖期限与顺延
- 编号层：`TicketCodeTest` 14 用例钉住「连续不跳号 + 让筛选不影响编号 + 插旧票顺移」
- 崩溃层：`CrashBeaconVersionTest` 钉住「版本号抽取」（抽不到按新崩溃处理）
- 报表层：钉住**各桶净收支之和 = 总账净收支**这个不变量

## 数据合规

本 App 仅本机使用，不联网回传账目。开奖数据接口为彩票机构官网公开页面，
仅用于个人对奖核对，不集中采集、不转分发、不改作商业用途。
